# Sample clients (all made up)

Ten made-up Ontario corporations, each with a year of bank and card transactions, what the client app would hand over at onboarding, and an answer key. They are the first version of the test world (decision 0008, Z8-8): loaded into QBO test companies, run through the Taxprep trial, and later used by the build's tests. The build's test-world cards extend these ten; they never invent a second set.

## Rules
- Everything is made up. Company and person names end in "(Test)"; inside bank descriptions a person's name carries the word TEST. Business numbers and SINs are generated to fail their check digit, so none can belong to anyone. Banks, card issuers, brokers and customers are made up; merchants may be common chains (fuel, coffee, telecom, software, groceries) because real statements always show them.
- Amounts in dollars and cents with two decimals, no thousands separators. Ontario HST 13%.
- Every account's balance rolls: opening plus the month's activity equals closing, every month, except where a client's planted fault says otherwise.
- Regenerate with `node reference/sample-clients/generate.mjs` (fixed seed, no packages). Check with `node reference/sample-clients/verify.mjs`.
- GIFI codes come only from CRA's GIFI guide (RC4088). A mapping that guide does not settle is marked "confirm" for the CPA.
- Taxprep computes tax. Answer keys hold inputs (GIFI lines, schedule inputs, additions by CCA class, adjusting entries) and the flags that must fire, not tax payable.

## Taxprep import CSVs (for trial days 2 and 5)
Each client has `taxprep/import.csv`: the GIFI amounts whose Taxprep cell the trial has confirmed, in the trial's own format (header `[name|0|0|GUID],"Current Year","Last Year",""`, rows `id,"whole dollars","",""`, Windows-1252, CRLF, all values quoted; no blank cells, RT-12; no year start or end, RT-13). Taxprep refuses cents, so each code is rounded half away from zero and the rounding difference goes on GIFI 3600 so Schedule 100 still balances. S1 net income is calculated by Taxprep and never written. Balance-sheet forms beyond S1599 and Schedules 1, 8 and 50 are not mapped yet and are left out. Status: `reference/taxprep/cell-map-status.md`.
- Regenerate: `node reference/sample-clients/make-csv.mjs`. Verify only: `--check`. List what each file leaves out: `--list`.
- Identifiers live in `lib/taxprep-cells.json` with their source file.
