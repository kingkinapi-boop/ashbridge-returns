# QBO features tried (decision 0011)

- Developer dashboard > My Hub > Sandboxes (developer.intuit.com/sandbox-companies?tab=qbo): lists and creates sandbox companies. Error banner on 1 Oct, list not shown. Matters to the build: yes (it is the test books).
- Developer dashboard > My Hub > Playground (developer.intuit.com/app/developer/playground): OAuth 2.0 playground that calls a few Accounting API reads once a workspace, app, keys and scope exist. Not used yet. Matters to the build: yes, it is the route to the report pulls, but it needs an app and keys made by Zo.
- Sandbox company "Sandbox Company CA 7cf6" (sandbox.qbo.intuit.com, Zo's tab): opens and works from the company screens, no API. Matters to the build: yes (it is the test books).
- Reports > Standard reports, report search box, then report page (Customize, Save As, export icon). Matters: yes. Export icon gives Excel, PDF, CSV; the CSV lands in Downloads with a name like "<company>_<report>.csv". Direct link pattern /app/reportv2?token=TRIAL_BAL (also JOURNAL) opens the report; GL and Transaction List are opened from the search box.
- Trial Balance (Debit, Credit per account, one row per account): no transaction id, no type, no GIFI. Customize has no id column. Matters: yes (account level only).
- Journal report (Customize > Columns, Groups): groups by Transaction ID by default (group heading "182" is the QBO transaction id of our JE, "Total for 182"); rows carry Transaction type and # (journal no. 15); optional Adj column. No Memo column and no attachments column. The JE memo does NOT show. Matters: yes (id comes from the group, memo missing).
- General Ledger (Customize > Columns): Distribution account, Transaction date, type, #, Name, Description, Split, Amount, Balance; optional Memo, Adj, Debit, Credit, Created by/on, Modified by/on. No transaction id column and no attachments column. The CSV did not carry the JE memo (it carries the line description). Matters: yes (type and # trace a row, no stable id).
- Transaction List by Date (Customize > Columns): one row per transaction; columns Date, type, #, Posting, Name, Memo, Account name, Split, Amount; optional Transaction ID, Created by/on, Modified by/on, Adj, Debit, Credit, REF #. The JE shows as one row with its memo in full, and amount and account blank. No attachments column. Matters: yes (best source for id plus memo).
- Journal Entry form (/app/journal): lines (account, debit, credit, description, name, sales tax, class), a Memo box, an Add attachment box (20 MB), Save, Reverse, Make recurring. Matters: yes (how AJEs are entered).
- Chart of accounts (/app/chartofaccounts): columns Name, Account type, Detail type, Currency, Default tax code, QuickBooks balance, Bank balance; Customize adds Description and account numbers toggle. No GIFI column. Matters: yes (GIFI mapping must live outside QBO).
- Top search for "GIFI": no results. No Workpapers or QBOA screen reachable in this company (the Accounting menu has "My accountant" only, not opened). Matters: yes (confirms no GIFI or Workpapers in the sandbox).
