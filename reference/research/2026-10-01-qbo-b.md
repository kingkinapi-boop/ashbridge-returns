# QBO year-end to T2 package, with a trail to source (angle B: Intuit help, Taxprep/TaxCycle help, practice guides)

Date: 1 Oct 2026. Researcher B. Pages opened via WebFetch (a small model summarises each page, so quotes are second-hand; check key ones by eye). Question: which QBO reports and exports feed a T2, formats, columns, GIFI mapping, how Taxprep and TaxCycle import a trial balance.

## 1. GIFI mapping lives in QBOA Workpapers, not in plain QBO

- [fact] Workpapers is a QBOA feature (accountant side, hidden from the client). It has a Working Trial Balance with an activity timeline, one-click drill to transactions, non-adjusting journal entries and reclasses, per-account-line file uploads and links, firm-only notes, and "Tax Mapping & Export": accounts are automatically assigned to tax lines and exported in GIFI file format. Corporate returns only. One accountant edits a client file at a time. https://quickbooks.intuit.com/learn-support/en-ca/help-article/manage-client/introducing-workpapers/L46ItXRic_CA_en_CA
- [fact] "Workpapers Tax Mapping" lets you edit the GIFI codes Intuit has already mapped, or assign codes to unmapped accounts; there is a "reverse the numerical attribute" checkbox (sign flip). Reached via the client's QBO, Books to Tax, Income tax. Output: GIFI file format. https://quickbooks.intuit.com/learn-support/en-ca/help-article/taxation/workpapers-gifi-mapping/L3CDlaaSK_CA_en_CA
- [fact] A practice guide (WRS Web Solutions) describes GIFI mapping as manual: export P&L, Balance Sheet, Trial Balance, General Ledger and Account List to Excel/CSV, then match accounts to GIFI yourself; it does not say QBO Canada stores GIFI codes. It ignores Workpapers; treat it as the no-QBOA fallback. https://www.wrswebsolutions.ca/QuickBooks-Online-Canada-Export-Data-Income-Tax-T2-GIFI-Codes.html
- [inference] So the account-to-GIFI mapping exists only inside QBOA Workpapers (and its export file). It is not an account field in QBO's chart of accounts export. Not found: any API route to read the Workpapers mapping. If we cannot call Workpapers, we keep our own mapping (blueprint TB-3 already says a confirmed mapping is reused next year).

## 2. The export from Workpapers

- [fact] Steps: QBOA, Clients, Workpapers for the client, Working Trial Balance tab (review), GIFI Mapping tab (every account has a code), then "Save GIFI codes", which downloads a .GFI file. https://www.taxcycle.com/resources/help-topics/data-import/import-gifi/export-gifi-from-quickbooks/
- [fact] Intuit Pro Tax T2 (inside QBOA) can create a return straight from "QuickBooks client Workpapers with completed GIFI Mapping", or from an external .gfi or .txt file; later re-import refreshes balances if the books change. Schedule 8 (CCA) cannot be completed from Workpapers. https://quickbooks.intuit.com/learn-support/en-ca/help-article/accountant-reports/accountant-t2-corporate-tax-returns/L6VqD1YPi_CA_en_CA ; https://quickbooks.intuit.com/learn-support/en-ca/help-article/accountant-reports/use-gifi-import-pro-tax/L4CdWQNLb_CA_en_CA
- [fact] Some GIFI codes are system-calculated totals (example 2008, total tangible capital assets); importing an amount to such a code breaks the Schedule 100 balance. Amounts belong on the component codes. Corrections go through Workpapers adjusting entries and Tax mapping. https://quickbooks.intuit.com/learn-support/en-ca/help-article/assets/certain-amounts-entered-gifi-codes/L0U5FKqTv_CA_en_CA
- [guess] The .GFI file carries GIFI code and balance per line, not transaction ids; no page I opened documents its columns (Intuit's Pro Tax page gives no column specification). We need a sample export to confirm.

## 3. How TaxCycle imports it

- [fact] TaxCycle T2 and T5013 import GIFI from .GFI, .CSV or .TXT; sources named include QuickBooks, Xero, Sage 50, CaseWare, AFP, CCH Engagement, or a custom spreadsheet. Drag the file onto the window or Data, Import GIFI. Amounts land on S100, S101, S125. It never overwrites the carried-forward company name and business number; notes in the export go to the Notes page; re-import is allowed. A "Sample QuickBooks GIFI Export.csv" ships with TaxCycle (shows the column layout; I could not open it). https://www.taxcycle.com/resources/help-topics/data-import/import-gifi/import-gifi-from-a-file/
- [fact] QuickBooks Desktop has no native GIFI export; TaxCycle's workaround is Reports, Accountant & Taxes, Income Tax Summary, export to CSV. https://www.taxcycle.com/resources/help-topics/data-import/import-gifi/export-gifi-from-quickbooks/

## 4. How Taxprep (CCH iFirm) takes a trial balance

- [fact] CCH iFirm Engagement (the trial balance module the Taxprep T2 sits with) has an "Import Trial Balance" page with a direct QuickBooks Online connection: choose Cash or Accrual basis, sign in with Intuit credentials, pick the company, Connect. Prior-year data cannot be imported from QBO (make one engagement per year and roll forward). Sub-accounts arrive as "Parent:Child" names joined by a colon. https://support.cchifirm.ca/en/content/cch_ifirm/engagement/trial-balances/uploading_trial_balance_data.htm
- [fact] Excel/CSV import wizard columns in order: Account Number (optional), Account Name, Current Debit, Current Credit, Prior Debit (opt), Prior Credit (opt); mapping options for classification, group, tax group; up to 10,000 accounts. GIFI codes are not mentioned on that page. Same URL.
- [guess] Re-import behaviour (names update, current balances zero then reload, prior balances and journal entries stay): seen only as a search result for https://support.cchifirm.ca/en/content/cch_ifirm/engagement/trial-balances/re_import_the_trial_balance_data.htm, not opened.
- [not found] Whether the Taxprep T2 itself (not Engagement) imports a QBOA .GFI file. A search result says Taxprep T2 "supports GIFI data import"; I did not open a page saying how. Wolters Kluwer's "[x]GIFI importing a Microsoft Excel file" page returned "Article not found". Open question for the trial week: try a .GFI and a CSV from Workpapers in the real Taxprep.

## 5. Transaction-level reports and the trail

- [fact, via a vendor guide] Journal report (Reports, For My Accountant) can show Date, Transaction Type, No., Memo/Description, Account No., Account, Debit, Credit, Created By, Created; exports to .xlsx or .csv. MindBridge recommends Journal over General Ledger for its imports. https://support.mindbridge.ai/hc/en-us/articles/5764222023703-QuickBooks-Online-Export-the-general-ledger
- [not confirmed] A search snippet says the GL report can show Date, Transaction Type, Num, Name, Memo, Account, Clr, Debit, Credit. I did not open a page that confirms it.
- [fact] Intuit community thread: Excel export is capped by a 400,000-cell limit (rows plus columns) and exports only the displayed columns, not the full record. It names no transaction-id or attachment column. https://quickbooks.intuit.com/learn-support/en-us/account-management/is-there-a-way-to-export-general-ledger-details-all-fields-in/00/1080185 (US page; Canada assumed the same: [inference]).
- [fact] Settings, Export data bundles reports and lists as Excel files in a .zip; attachments export as a separate .zip; individual reports export to Excel (the page does not list PDF or CSV). https://quickbooks.intuit.com/learn-support/en-us/help-article/list-management/export-reports-lists-data-quickbooks-online/L1xleDrLp_US_en_US
- [fact, thin] API: attachments link to transactions through an AttachableRef and download by temporary link (page came back truncated, details unverified). https://developer.intuit.com/app/developer/qbo/docs/api/accounting/all-entities/attachable
- [not found] The Intuit developer page for the GeneralLedger report returned nothing usable; I could not confirm whether the report API returns a transaction id, or the TrialBalance report columns.

## 6. What this means for Ashbridge Returns (inferences)

1. Report exports give number, type, date, memo, account and amounts but no confirmed transaction id and no attachment column, so a "QBO line" pointer built from a CSV needs date + type + number + account + amount as a composite key. The API (transaction ids, Attachable) is the likely route to a stable id and the attached file; needs a sandbox test.
2. The trial balance and the GIFI mapping have different homes: balances come from QBO (report or API; CCH iFirm reads QBO by login), mapping comes from QBOA Workpapers or our own table. Treat the mapping as ours (TB-3) and optionally cross-check against a Workpapers .GFI when the firm supplies one.
3. Prior-year balances do not come from QBO in Taxprep's import; we bring prior year from last year's return (TB-8), which fits.
4. The 400,000-cell cap and displayed-columns-only rule mean year-end GL exports for busy clients must be split by account or month, or read by API.
