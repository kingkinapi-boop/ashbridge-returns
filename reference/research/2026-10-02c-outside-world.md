Compaction and long runs: 2.1.288 fixes "Prompt is too long" instead of auto-compact when the last reply reported zero token usage; mid-response API timeouts now continue from the partial reply in subagents and non-interactive sessions; /autocompact is saved per model. 2.1.287 stops a folder's CLAUDE.md being attached twice after compaction. Q1 Hooks: 2.1.288 makes PreToolUse and PermissionRequest hooks block the call when matching fails or the input cannot be turned into JSON (before, they were skipped). Our ledger and push-guard hooks now fail closed on a bug. [fact, then inference] same CHANGELOG URL
Q1 Rules: 2.1.288 loads path-scoped .claude/rules and nested CLAUDE.md when Write or Edit touches a file in scope (before, only Read did). Only matters if our rule files use path scopes (not checked). [fact, then inference] same CHANGELOG URL
Q1 Cloud: 2.1.286 shows a routine run whose cloud session never started as Failed, not Succeeded; 2.1.287 fixes cloud sessions losing earlier conversation when restarted mid-compaction. 2.1.285 added a background-command time limit (default 30 min, max 2 h) and 2.1.288 narrowed it to unattended sessions (-p, SDK, CI, cloud). In cloud a command past its timeout moves to the background and is stopped 30 minutes later. Matters for the full suite run in the cloud. [fact, then inference] same CHANGELOG URL; https://code.claude.com/docs/en/cloud-environments (Time limits)
Q1 Worktrees: 2.1.286 makes /exit "Remove worktree" run after Claude Code stops the servers and shells it started there, which on Windows could keep the folder from being deleted. Our junction rule still stands. [fact, then inference] same CHANGELOG URL
Q1 Prompt caching: no change in 2.1.287 or 2.1.288. Standing: main conversation gets a 1 hour cache on a subscription within plan usage; subagents, workflows, forks and compaction get 5 minutes unless set with subagentPromptCacheTtl, CLAUDE_CODE_SUBAGENT_PROMPT_CACHE_TTL or frontmatter experimental.cacheTtl (1h ignored while on usage credits). [fact] https://code.claude.com/docs/en/prompt-caching (Which TTL each request gets); https://code.claude.com/docs/en/sub-agents
Q1 maxTurns still exists; at the limit the subagent returns partial output and can be resumed. [fact] https://code.claude.com/docs/en/sub-agents
Q2 YES. CLAUDE_AUTOCOMPACT_PCT_OVERRIDE exists, can only lower the trigger, and "applies to both main conversations and subagents". [fact] https://code.claude.com/docs/en/env-vars (line 196); https://code.claude.com/docs/en/sub-agents (line 1127)

[fact] https://code.claude.com/docs/en/claude-code-on-the-web (line 258)
