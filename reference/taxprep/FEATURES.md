# Taxprep trial features seen (one line each: menu path, what it does, matters to build?)

- Dashboard footer: shows platform release CCH iFirm 2026.20.198267. Matters: record per run.
- Taxprep > T2 Corporate (returns list): trial banner shows days left (15 on 1 Oct) and PDFs left (100); edition picker "2024 and later"; columns include Business Number, Return Status, T2 EFILE, Tax Year Start/End, Label. Matters: yes, return list is the build's lookup.
- Returns list buttons: Add return, Roll forward, Quick filters, Actions (export lives here), PDF (metered), EFILE (never), Search. Matters: Add return, Actions yes.
- T2 Add return dialog: client name, optional business number, year start/end typed YYYY-MM-DD, label, assignees (preparer/reviewer/manager/partner), public/private. Also creates an iFirm contact. Matters: yes (return creation inputs are small).
- Return workspace tabs RETRIEVE / PREPARE / REVIEW / TRACKING; Quick entry bar (Box, Value); Cell details and Tools panes; Diagnostics panel with All/General/Filing/Custom/Reviewed. Matters: yes (diagnostics are the checks to mirror).
- Return URL embeds a GUID and form code (prepare/<FORM>). Matters: maybe, for deep links.
- Forms picker (Forms button): 395 forms, search, filters by Jurisdiction and Type, jump codes like S100, S1, S125, S141 (not plain numbers). Matters: yes (form identity for trace).
- ID form: cells have numeric box numbers (001 BN, 002 legal name, 750 province); Client Code autogenerated; "Automatically synchronize contact information" Yes/No. Matters: yes (cell id shape = box number).
- Diagnostics panel: coded messages like (R2000100) with type EFILE/General, form, jurisdiction. Matters: yes.
- REVIEW tab > Filters panel: built-in filters (Entered this/last year, Overridden, Edited after CRA/RQ import, Imported, Breakdown, Spreadsheet, Rolled forward, Track changes; cells with review marks / comments / diagnostics), Custom filters, Combine filters; Client Letters tab. Matters: yes (Imported and Overridden filters give provenance).
- Custom filter builder (Add): pick a form, Select all input cells, Add selected cells, name, Add filter; shared per tax product. Matters: yes (cell list per form, Box and description).
- S125 income statement uses GIFI codes (8089, 8299, 9368...) as cell boxes. Matters: yes (trial balance to GIFI mapping).
- Date cells on ID form: 060 year start, 061 year end, 990 language, 002 legal name. Matters: yes.
- Actions > Export... (CSV | Excel | Taxprep): CSV options column break (tab/comma/semicolon/space), negative style, decimal and thousand separators; filter picks which cells; async with a notification then a Download link. Output: Windows-1252, CRLF, comma, all values quoted, empty cells listed, header [name|0|0|GUID],"Current Year","Last Year","". Matters: YES, this is the trace backbone and the import template.
- Cell identifiers in the export look like IDENT.Ident120 and GFBGII[1].GFGII.Ttwgii4 (not box numbers); [n] is the copy index. Matters: YES (the build's CSV writer and trace key).
- Actions menu: Import data using the T2 Auto-fill service (day 4 only), Notice of Assessment, Import from GIFI, Import the CSV or Excel file, Import and link corporations, Retrieve Web Access Code, Copy, Rename, Lock, Manage visibility, Audit Trail, Manage spreadsheets, Roll forward, Delete. Matters: Import from GIFI, Lock, Audit Trail, Roll forward yes.
- Top bar bell with badge opens firm release notes (/#/fe/release-view), not return notifications; the return's own bell holds export notifications. Matters: no.
