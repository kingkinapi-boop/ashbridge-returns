Preparer workbench: three versions to compare

Made-up sample clients only (Maple Ridge Consulting Inc. (Test) is the main return). Each version follows the same ten task scripts in the same order. They differ in structure.

  • Version A: a return record page with tabs, one job per tab (all pages and states)
  • Version B: steps down the left, a list in the middle, a detail and source pane at the right (all pages and states)
  • Version C: worklists across returns, a small return page, the source in a second window (all pages and states)
