CPA review and its source viewer: three versions

Made-up returns from the sample clients. Each version covers the same tasks: pick a return, read the brief, walk each section, check numbers against their sources, step through flags, comment, mark each section Reviewed, approve, and re-review after rework.

Reviewed is an explicit mark on each section (key m), with who and when. It comes off, with the reason, when a number in that section changes. Approve appears only when every section is marked.

Open Version A. Record page with tabs; return, trace and source side by side; the source can pop out to the second monitor.
Version B: coverage rail, list and detail
Open Version B. A rail of sections with their marks on the left; the section in the middle; trace above source on the right.
Version C: return walk with the source on the second monitor
Open Version C. The return full width on the laptop with the trace opening under each line; the source lives in its own window on the second monitor.
