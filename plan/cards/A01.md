## Goal
The free reading engine for born-digital PDFs: every word on every page with its box, in F09's shape, behind the reading adapter, so documents can be read and citations checked with no paid service and no key.

## Build
- `src/modules/ocr/index.ts`: the reading adapter (F09's interface) with an engine switch. Engines: `textlayer` (this card); `tesseract` (A02) and `recorded` (A03) slot in later; `live` exists only as a named slot that is off, holds no key and refuses to run (GL1 builds it). The default is `textlayer`.
- `src/modules/ocr/textlayer/`: reads a PDF's text layer with a free, open-source library (pdfjs-dist or similar; no account, no key, no network; exact version pinned, `npm audit` clean). Returns words with boxes as page fractions (origin top left, F09's converter), page sizes, rotation applied, the engine name and library version.
- A page with no text layer (a scan) is returned as "no text layer" for that page, never as an empty success, so intake can route it to Tesseract.
- Word boxes are computed once per document fingerprint and reused (ARC-11); a second read of the same bytes does not parse again.
- No network, no writes outside a temp folder; a PDF that is encrypted or broken is refused with the reason.

## Test fixtures (spec-writer, `src/modules/ocr/textlayer/__fixtures__/`)
- Small made-up PDFs built by a committed script with fixed content: one page with known words at known positions (including "$1,234.56" and a date); a rotated page; two pages; a page with an image and no text; an encrypted file. Each with its expected words and boxes as JSON.

## Acceptance checks
1. ARC-6: reading the one-page fixture returns every expected word with its box within one hundredth of the page, and F09's schema accepts the result.
2. EV-6 through F09: `valueInBox` finds 1234.56 in the box the fixture puts "$1,234.56" in.
3. A rotated page gives boxes in the page's upright frame (the same box as the unrotated fixture).
4. The image-only page is reported as "no text layer" with its page number; the other pages still read.
5. An encrypted or broken file is refused with the reason; nothing is written.
6. ARC-11: a second read of the same bytes returns the stored words without parsing again (a counter or spy on the parser shows one parse).
7. ARC-6, END-8: the `live` engine is off by default; switching to it with no key fails with "live reading is off until go-live", and switching back to `textlayer` works (both directions tested).
8. END-8: the new dependency needs no account, key or payment, and `npm audit --audit-level=high` stays clean.
