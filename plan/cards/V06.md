## When it starts
This card waits until D05 (the round-trip checklist) is approved by Zo at a design sitting (RV-53); the Lead marks D05 done then.

## Goal
One screen per return takes the preparer through the Taxprep round trip in order, each step showing whether it is done and what proves it, so nothing is skipped and nothing is taken on trust: upload the .GFI, download the import file, import it into Taxprep, make the tax choices in Taxprep, lock, upload the lock export and the printed return, clear the diagnostics, cite every orphan, sign off.

## Build
- `src/app/(staff)/prepare/roundtrip/`: built to D05's approved design, a page per return reached from the queue (V05) and the return record, listing the steps in RV-21's order (with the .GFI first, A164). Each step shows done, to do or blocked, and the evidence for done:
  - **GIFI mapping**: upload the .GFI from QBO (B01 `importGfi`); its refusals and TB-3 flags shown with their reasons.
  - **Import file**: download the latest file (T01), named as RT-5 says; figures "waiting on verification" and "held back until the first export" listed with links (RT-7: the import itself makes a new copy at the next free index; with no export since the return was created, new rows wait for one); a re-import shows only its changed and cleared cells; cells Taxprep still holds whose figure is gone or waiting (T01 `stillHeld`) are listed, each with a "Clear in the next file" action that asks for a reason (T01 `requestClear`).
  - **Import into Taxprep, tax choices, lock**: the preparer's own steps in Taxprep, listed with the tax-choice cells (M00) to decide. "I imported it" is not proof: the step shows done only when an accepted lock export traces the import's cells (RT-26). The lock step ends with a "Ready" button (blueprint 02: prepare leaves when locked and Ready is pressed) that calls T12's `markReady` and moves the return to trace, where the uploads open.
  - **Upload the lock export and the printed return** (one form, two files): T02's and T07's refusals shown by reason, with the fix (for example "add IDENT.Ident121 to the lock filter"). Server-side checks before anything is stored: file type, a size limit, the return the preparer holds (SEC-2, FLOW-10).
  - **Diagnostics** (T05, RT-17): the preparer pastes the list copied from Taxprep's Diagnostics panel (the All tab, Hidden rows included) with the lock export; blocking ones listed; a reason box for each Warning and each Information or Filing warning; an unknown code or severity shows as Error until a person classes it.
  - **Cite and explain**: counts of orphans, overrides, dropped cells and "changed outside the trace" from T12's `blockers`, linking to the cite list (V12).
  - **Sign off**: a button that calls T12's `signOff`; while blockers remain the page lists them as links instead (rule: no disabled buttons, RV-10's pattern), and after sign-off the return shows in respond.
- Every action is a server action through the data-access layer (SEC-2), takes the return's hold into account (FLOW-10), and shows GOV.UK error summaries for refusals.
- Shortcuts through U01; the page keeps its place when coming back from V12.

## Test fixtures (spec-writer)

## Golden files (spec-writer)
- The ARIA snapshot of the checklist in three states (fresh, blocked, ready to sign off) (`e2e/staff/__golden__/`).

## Acceptance checks
1. RV-21: the steps appear in the approved order; each shows its state and evidence; the golden ARIA snapshots match.
2. TB-3: uploading the .GFI calls `importGfi`; a file mapping an account to 2008 shows the refusal with RC4088's reason.
3. RT-5: the download gives T01's latest file with its name; waiting and held-back figures are listed with links; a cell Taxprep still holds is cleared in the next file only after a reason is entered (an empty reason shows an error summary and records nothing).
4. RT-26: the import step is not marked done by a button press; it is done only after an accepted lock export traces the import's cells.
5. RT-1, RT-11: the wrong-client export, the export missing `IDENT.Ident121`, the non-PDF and the oversize file are each refused with their reason in an error summary, and nothing is stored for the oversize or non-PDF file.
6. RT-17: the pasted list is read by code and cell; an Error or Filing error blocks with no reason box; the Warning's reason is saved with the preparer's name; an unknown code or severity counts as Error; a Hidden or Ignored diagnostic never counts as cleared.
7. RT-18, FLOW-2: "Ready" moves a return in prepare to trace and opens the upload step; with blockers, Sign off is replaced by the list of blockers as links; with none, signing off moves the return to respond and saves the preparer version.
8. SEC-2, FLOW-10: a preparer cannot open or post to a return not assigned to them, or held by someone else.
9. RV-53: the page matches D05's approved pages within the visual threshold, and D05's click and page-load budgets for "upload the lock export and printed return" and "sign off" hold.
10. RV-54: U02's sweeps pass; the whole round trip works by keyboard alone.
