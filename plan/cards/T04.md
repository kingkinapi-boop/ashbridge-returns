## Goal
After the preparer locks and uploads the lock export, every cell in it is put in exactly one of RT-14's six classes, so Returns knows which values it put there, which a person changed or lost, which came from last year, and which nobody has sourced. The import report proves nothing (RT-26); this comparison is the proof. Resolving what the classes find (cites, reasons, the sign-off gate) is T12's.

## Build
- `src/modules/roundtrip/trace/`:
  - `traceExport(exportId)`: for each cell of an accepted lock export (T02), with the return's import history (T01) and the release's lists (M00), one class from F03's six (RT-14), first match wins in this order:
    1. **calculated**: on the release's calculated list and not a tax-choice cell (M00 `taxChoiceCells`);
    2. **traced**: Returns' last import of the cell holds this value (or cleared it, and the export holds `""`);
    3. **overridden**: Returns' last import filled the cell and the export holds another non-empty value; also a cell Returns cleared that the export still holds (RT-8: "clear not applied"); and every cell T02 returned as "differs from import N" (RT-2's content test);
    4. **dropped**: Returns' last import filled the cell and the export holds `""`, or the cell's natural key is one T02 returned as "missing" (its copy was deleted) (RT-14: "blank or missing"); a missing natural key gets one dropped row per imported cell of that copy, keyed by natural key;
    5. **rolled forward**: never imported, filled, named in M00's roll-forward map, and equal to the value of its `priorFactKey` fact (RT-24); the cell is registered as a fact sourced to last year's return (EV-5) through the ledger contract, once per lock export;
    6. **orphan**: filled and none of the above, including every filled tax-choice cell (TB-6, even when Taxprep computed it) and every cell on the allowed-typing list (RT-15). Allowed-typing orphans are marked `allowed` and need no source; every other orphan needs one (RT-16, through T12).
    Empty cells that Returns never imported get no class.
  - Rows are keyed by figure key and natural row key (M00) as well as identifier, so a renumbered copy (S01's reordered copies) is matched to the import that wrote its natural key, never by copy number.
  - `data/taxprep/allowed-typing/<release>.json` (RT-15): Taxprep settings and e-file option cells, plus the return-creation and contact cells the trial saw (`IDENT.Ident120`, `Ident121`, `Ident311`, `Ident230`, `Ident451`, `Ident492`, `IFirm.ContactPartner`), each with its source note. The year dates, name and business number stay checked by T02 (RT-1).
  - `changedOutsideTrace(exportId)` (RT-20): compared with the return's previous accepted export of the same kind: T02's "no change" ends it; otherwise a cell-by-cell diff, and every differing cell with no recorded import between the two exports is flagged "changed outside the trace" with both values. Cells changed by an import in between are not flagged.
  - The classes and flags are stored per export in `db/schema/45_roundtrip.sql` (append-only), with the counts per class, and returned as one trace result carrying the export, the import versions, the mapping release and fingerprints and the code release (ARC-10).
- `src/pipeline/steps/trace.ts` replaces F10's placeholder; the skeleton's trace stub is removed from `stubs.ts` and `stubs.md`.
