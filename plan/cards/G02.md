## Goal
After code has drafted the question list, AI fills the slot values (an amount, a date, a document name) for the questions code picked, and may add short observations for the preparer, each with citations that code checks. AI never adds or removes a question, never words one for a client, and never decides a gap.

## Build
- `src/modules/gaps/slots/`:
  - A versioned prompt (`prompt.md`, its version and hash in the stamp) and an F04 output schema: for each draft question id, a value per slot with its citation (a ledger record, a document box, or a return cell, AI-1), or "I can't tell" for that slot (AI-6); and a list of observations for the preparer, each with at least one citation. No free text field is sent to the client app.
  - `fillSlots(listId)`: runs through I00's grounded step (redaction first, the AI runner, the schema, the citation check), with the draft questions, their gaps' facts and the pointers G00 looked at as inputs. Then code checks:
    - a question id in the output that is not on the draft list is dropped and counted against the step (AI cannot add a question);
    - each slot value must fit the slot's type (money in cents, a date, a document or account reference that exists on the return, an option id the slot lists); a value that does not fit is dropped and counted;
    - a money or date value must be found in its cited box or cell by I00's citation check; a failed citation drops the value and counts against the step (AI-4);
    - "I can't tell" leaves the slot empty and marks it for the preparer (AI-6).
  - Filled values are written as a new version of the draft list with the AI stamp; the preparer keeps, edits or drops them on the gap review screen (V08). Nothing here signs or sends a list, and no fact or gap status changes (AI-7).
  - Observations are staff-only notes on the draft list with their citations; a failed citation drops the observation.
- `src/modules/gaps/index.ts` gains `fillSlots`.

## Acceptance checks
1. AI-12, AI-1: the good recorded answer fills the slots as in the golden file, each value with its citation and the AI stamp; the question ids and their order are unchanged.
2. AI-12: the output that adds a question id is cut back to the draft list's ids, and the added one is counted against the step.
3. AI-4: the slot value whose cited box does not hold it is dropped and counted; the date in a money slot is dropped and counted; neither reaches the list.
4. AI-6: the "I can't tell" slot is empty and marked for the preparer.
5. AI-7: after `fillSlots`, no gap status, fact status or lifecycle state has changed (a before and after comparison), and the list is not signed.
6. END-7: the filled list holds no free text for a client: only slot values of the slot types, and observations are stored on the staff-only side (a schema check over the hand-off rows `toHandOff` would write).
7. The observation with no citation is dropped and counted; a cited observation is kept with its citation.
