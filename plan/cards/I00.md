## Goal
Every AI step in Returns goes through one wrapper: inputs are redacted before the call, the output is schema-checked, every citation is checked by code, and what fails is dropped and counted. A finding about something missing is kept when it cites where the thing should be, "I can't tell" goes to a person, and nothing AI says changes a status. The runner (A04) refuses unredacted input; this card is the redactor and the checker.

## Build
- `src/modules/ai/grounding/redact/` (AI-9, SEC-5):
  - `redactText(text, context)`: masks SINs (nine digits, with or without spaces or dashes, whatever their check digit), dates of birth (dates on a fact whose key E03 marks `birth_date`, and dates next to the words "date of birth" or "born"), and bank and card account numbers (runs of 7 to 19 digits next to account, transit, card or institution words, and any value of a fact key E03 marks `bank_account`) with a fixed token per kind (`[SIN]`, `[BIRTH DATE]`, `[ACCOUNT]`). Returns the masked text and a count per kind, never the values.
  - `redactPageImage(page, wordBoxes)`: a copy of the page image with an opaque black box over every word the text rules match, written write-once to the file store through the storage contract and keyed by the original image's sha256 plus the redactor version; the original is kept. The same input gives the same bytes.
  - `redactInputs(job)`: applies both to every text and page image in an AI job, and adds the redaction stamp A04 requires (redactor version, counts per kind, who ran it).
- `src/modules/ai/grounding/cite/` (AI-1, AI-4, AI-5):
  - A citation is exactly one of: a ledger record (fact, account, adjusting entry, link) by id; a document box (document, page, box); a sheet cell (file, sheet, row, column); a return cell (version and cell identifier).
  - `checkCitation(citation, quoted?)`: the record exists (through the ledger and documents contracts); for a box, any quoted number or words are found by F09's `valueInBox`; for a cell, by A07's `cellValueMatches`; for a return cell, the cell exists in the named version (through a versions contract passed in; return versions arrive in phase 2, so until then tests pass a typed fake of that contract). Fails with the reason.
  - `checkOutput(step, output)`: each item with a citation that fails is dropped and counted against the step (the per-step counter A04 keeps). An item marked "missing" (AI-5) passes when it cites where the thing should be (a document, a page or a return cell that exists) and is kept. An "I can't tell" item (AI-6) is kept and routed to a person as an open question, never dropped and never turned into a value.
- `src/modules/ai/grounding/step.ts`: `groundedStep(step, inputs, deps)`: redact, then A04's `runAiStep`, then F04's schema (A04 does it), then `checkOutput`; returns the kept items with their stamps (AI-10: model, prompt version and hash, input hash, OCR engine and version, mapping release; an output missing any is refused) and the dropped items with reasons for the counters.
- AI-8: document text goes into the prompt only inside a fixed data envelope (`<document id=...>` ... `</document>`), with the step's orders outside it, built by one function every step uses; the schema allows no field that asks for an action (no status, approve, clear, close, send or write field exists on any AI output schema), and a test sweeps every AI output schema in `src/` for such fields.
- AI-7: the wrapper has no access to status changes: it is given read-only ledger and documents contracts (a type test), and kept items are returned to the calling step, which may only propose.
- `src/modules/ai/index.ts` gains the grounding exports.
- Box (findings F01-F09, RC2): every box this card writes, stores or reads is F09's Box shape (page plus left, top, width and height as page fractions, BoxSchema from src/contracts/reading.ts), never its own {x0,y0,x1,y1}.
- Version stamps (findings F01-F09, R14): every version stamp this card writes is non-blank scalars only; {}, {"x":null} and {"x":""} are refused by F01's SQL check and VersionStampSchema, so the spec names the stamp's fields and values.

## Lead note (findings review wave 2, 2 Oct, fix 1a and RC2)
F04 adds a citation kind `page` (`documentId`, `page`; no quote, no box), allowed only on a "missing" finding, whose citations are each a document box, a page or a return cell. `checkCitation` for a page checks that the document exists and has that page (through the documents contract), and nothing else (there is nothing quoted). The spec adds: a "missing" finding citing a page beyond the document's page count is dropped and counted; check 5's "existing page" uses this kind. Every schema this card defines is strict at runtime (SC R23), and it parses engine results through `ReadingResultSchema` before `valueInBox` (F09A note 4).
