Match the client app's major versions where safe (read `C:\Users\User\Documents\GitHub\ashbridge-app\package.json`, read-only). Node 24, npm 11 (`.nvmrc`). Home page: "Ashbridge Returns. Staff only." and nothing else.
- **Dependencies:** `.npmrc` with `save-exact=true`, `min-release-age=7`, `engine-strict=true`; lockfile committed; `npm ci` everywhere. zod v4 and fast-check as dependencies from day one.
- **Tests:** Vitest with projects `unit`, `db` and `evals` (evals outside the default run), the `agent` reporter, `TZ=America/Toronto`, capped `maxWorkers` locally and a private temp folder per run. PGlite in `src/core/db/`: load `db/schema/*.sql` once per worker, `clone()` per test (an empty folder is fine). ## Acceptance checks
1. `npm run typecheck`, `npm run lint` and `npm run deps:check` pass.
2. `npm test` runs at least 7 tests and passes: a database is created from the schema folder and cloned; the clock can be pinned; money adds in cents and the rounding rule holds (a fast-check property); ids sort by creation time; the logger never prints a planted SIN; `env.ts` never prints a value; a test in `src/core/` imports `tools/lib.mjs` and shows `globToRegExp('src/**')` matches `src/a/b.ts` and not `srcx/a`.
3. The workflow is valid, skips the claims, train and review branches and documentation-only pushes, and runs no journeys.
4. `npm run e2e` passes in the cloud against the production build (not on the laptop).
5. `npm audit --audit-level=high` is clean; no dependency needs an account, a key or money.
6. `node tools/scope.mjs F00 main` is clean.
