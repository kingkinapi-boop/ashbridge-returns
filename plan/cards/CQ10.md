## Goal
A04's tests passed for a day and failed when the date rolled (A469): a test pinned one clock and not the other. `test:flake` reruns on the same day, so it cannot see this.

## Spec
- `npm run test:flake:shifted` runs the unit project once with the system date shifted forward by 2 days and once by 1 year (a fake-timer or `TZ`-safe date shim set before any test file loads), and fails naming any test whose result differs from the unshifted run.
- Planted: a test that compares a fixed date with `Date.now()` fails under the shift and is named.
