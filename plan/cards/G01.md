## Goal
The approved question bank is a catalogue of ids, slots and answer shapes, each tied to the fact it resolves, with no wording at all: the client app words every question (ARC-2, RULE-19). This card fixes the format, the loader and the lint, so the topic cards (G10 to G17) only add items and the gap pass (G00) and slot fill (G02) can rely on them.

## Build
- `data/question-bank/_schema.json` (JSON Schema): an item has `id` (`Q-<TOPIC>-<nnn>`, never reused), `type` (`ASK`, `CONFIRM` or `DECIDE`, as the client app's Q&A spec defines them), `resolves` (one fact key from E03's catalogue), `slots` (each with a name, a type: money in cents, date, count, percent, a document reference, an account reference, a fact reference, or a choice from listed option ids; and whether it is required), `answer` (the shape the client's answer takes: money, date, yes or no, one of listed option ids, a file, or a number), `label` (a staff-only label of at most 60 characters, no final full stop, never shown to a client), `topic`, and `retired` (true for an item no longer offered; its id stays reserved).
- `src/modules/gaps/bank/`:
  - `loadBank(dir)`: reads every `data/question-bank/*.json` except `_schema.json`, validates each item against the schema, and refuses with the file and item: a duplicate id across files, an id in the wrong pattern, a `resolves` key not in E03's catalogue, a slot type the fact's value type cannot take (for example a money slot on a date fact), and a retired item that a non-retired item reuses. Returns the bank with a version (a hash of every file).
  - The no-sentence lint (RULE-19, END-7): no string anywhere in a bank file may read as a sentence to a client: no final full stop, question mark or exclamation mark, no second-person words ("you", "your"), at most 60 characters in a label. A failing item is refused with the reason.
  - `pick(bank, factKey)`: the non-retired items that resolve a fact key, in id order.
  - `toHandOff(list)`: a signed question list as the hand-off rows the client app reads (question id, slot names and values, the return, the bank version), with no label and no text; F07's hand-off table shape.
- `src/modules/gaps/index.ts`: the module's public exports (G00 and G02 add theirs).

## Test fixtures (spec-writer, `src/modules/gaps/bank/__fixtures__/`)

## Golden files (spec-writer, `src/modules/gaps/bank/__golden__/`)

## Acceptance checks
1. ARC-2: the valid fixture bank loads with a version; each bad copy is refused naming the file, the item and the reason.
2. RULE-19, END-7: the label ending in a question mark and the label holding "your" are refused by the no-sentence lint; property (fast-check, fixed seed): any generated label that ends in a full stop, a question mark or an exclamation mark, or runs past 60 characters, is refused.
3. ARC-2, END-7: `toHandOff` equals its golden file and holds no label or other text, only ids, slot names, slot values, the return and the bank version.
4. AI-12: `pick` returns only non-retired items that resolve the fact key, in id order; a retired item is never picked.
5. The bank version changes when any item changes and not when a file is re-saved unchanged.
