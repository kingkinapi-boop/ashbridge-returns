## Spec (a spec worker who did not spec F09A; each test fails on fc17ad4 for the right reason, step 6b sweep)

An overlapping pair (the second starts inside the first) does not join. A gap at exactly 0 and at exactly the tolerance joins; just past the tolerance does not.
2. Rule test (runs over every geometry predicate in amount-grammar.ts): each has a table row with a backwards gap and an overlapping gap.
3. Blank word: a word made only of Unicode format characters (category Cf, for example U+200B, U+2060, U+200E, U+00AD, U+180E, U+FEFF) is blank and refused by WordSchema; a word with one visible character plus format characters is not blank.
4. Mixed grouping: "1,234" "567" (comma groups then a space group) is not one amount; the table says which reading wins and the test pins it.
5. Speed: 50000 "000" group words after a "1" return within 2 s (joining is linear, not a growing-string regex per word).
