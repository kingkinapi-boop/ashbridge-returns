## Goal
The behaviour every staff screen shares, built once, and the staff-screen rules turned into sweeps that run on every screen of every test-world kind, so a fault found once is caught everywhere. Each sweep is first shown failing on a planted bad page. With no screens built yet, the sweeps run on the planted pages and U00's gallery; each V card's screens join them by being listed in D01's map.

## Build
- `src/ui/behaviour/`:
  - `ReturnFrame`: the page frame every return screen uses: the Generic header with the logo, the skip link, one h1, the `<title>` as "<page> - <corporation> <year end>" (with "Error: " first when the error summary shows), and the MOJ identity bar naming the corporation and year end (RV-50, rule 4).
  - `mask.ts` (SEC-4, rule 15 and 23): `maskSin` (always "SIN on file", no digits), `maskBirthDate` (year only), `maskAccount` (last four digits), applied by the money, text and summary-list components to any value whose fact key E03 marks sensitive; there is no prop that shows a sensitive value unmasked.
  - `HoldBanner` (FLOW-10): who holds the return and since when, from F02's hold contract; "Take this return" when it is free or the hold has expired, "Release" for the holder; acting without the hold is refused on the server and the page says who holds it. The 4-hour idle expiry is F02's.
  - `StatusWords`: the one word and colour per status, dot, tier and flag (rule 7), from one table, so the same status reads the same everywhere.
  - `pending.ts`: the loading state on any button that waits on the server and a block on a second submit (rule 9; U00's button gives the look).
- `e2e/rules/` (cloud, through JH0's harness and its shared axe fixture, against the production build):
  - `routes.ts`: every staff route listed in D01's `design/map/screens.md`, with the states worth reaching; a route the app serves that the map does not list, or a listed route the app does not serve once its V card is done, fails.
  - One sweep file per automatable rule of `.claude/rules/staff-screens.md` (1, 3, 4, 5, 6, 7, 8, 10, 11, 12, 13, 15, 16, 18, 21 and 23), each run on every listed route for every test-world kind that has data for it: classes only `govuk-`, `moj-` and listed `app-`; axe with the five WCAG tags; one h1, skip link, header, title and identity bar; table captions and scoped headers, money in numeric cells, one figure printed the same everywhere on the page; sortable lists over 5 rows; words beside every colour; no disabled button and no dead control; shortcuts with visible controls; keyboard-only walk with visible focus; 24 px targets; 320 px reflow; no planted SIN, birth date or account number unmasked anywhere on the page or in its page images; no placeholder, "coming soon", lorem ipsum, em dash, or unlabelled field; the two window sizes of rule 18; search or a filter on lists over 5 rows.
  - `__planted__/`: one planted bad page per sweep (static HTML or a test-only React page outside `src/app`) that the sweep must fail with the rule's number and the reason.
  - A sweep that finds no route to check fails ("a pass with zero tests is a failure").

## Acceptance checks
1. RV-50, RV-54: each sweep fails its planted bad page with the rule number and the reason, and passes U00's gallery page.
2. SEC-4: `maskSin` shows "SIN on file" for every planted SIN; `maskBirthDate` and `maskAccount` show only the year and the last four digits; the planted-value sweep finds every planted SIN, birth date and account number on its planted page and none on the gallery.
3. RV-50: `ReturnFrame` renders the title, identity bar, skip link and one h1 for a C01 return; with the error summary showing, the title starts "Error: ".
4. FLOW-10: `HoldBanner` shows the holder; a second preparer sees "held by" and no take action until the hold expires on the pinned clock, then sees "Take this return"; a server action by someone without the hold is refused with the holder named.
5. RV-52: `StatusWords` gives each status one word and one colour, and every dot, tier and flag status the blueprint names has an entry.
6. RV-50: `routes.ts` fails when the app serves a route the map does not list, and a sweep with zero routes fails.
7. RV-54: a button waiting on the server shows its loading state at once, and a second click sends nothing (a counter).
