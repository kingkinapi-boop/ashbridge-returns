## Goal
The question-bank cards G12 to G17 each need at least one client-askable fact (origin onboarding or qa) per topic, and a fact belongs to exactly one bank item. The G12 spec found none for assets and CCA: R27 (an asset bought but not yet available for use) and R28 (an asset sold or written off in the year) have no askable fact. Before G12 to G17 are specced, the catalogue gains the askable facts their rules read.

## Spec
1. For each topic G12 (assets, CCA), G13 (shareholders, dividends), G14 (payroll, bonuses), G15 (shareholder loans), G16 (vehicle, home, office), G17 (CRA, HST, instalments), a table test names the blueprint 05 rows the topic's questions resolve and asserts the catalogue has at least one askable key citing each row, with no key shared between two topics (the one-fact rule).
2. New keys carry value type, sensitivity and cite pattern per E03's rules; R27 and R28 have keys (for example `qa.assets.purchased_not_in_use` and `qa.assets.disposed`), named by the spec worker from blueprint wording.
3. The existing vehicle keys stay with G11 (expenses) and are not reused by G16.
