## Goal
Every record in blueprint 03 exists as a table in schema `returns` and as a TypeScript type, so later cards build in parallel against a fixed shape.

## Build
- One SQL file per module in `db/schema/`: `00_schema.sql` (schema returns), `10_documents.sql`, `20_ledger.sql` (facts, links, events), `30_books.sql` (accounts, entries, entry lines, judgment inputs), `40_figures.sql`, `50_returns.sql` (returns, state events, holds), `60_versions.sql` (versions, version cells, approvals), `70_checks.sql` (check results, exceptions, answers), `80_jobs.sql`, `90_learning.sql` (differences, lessons). F07 adds `05_bridge.sql` and F06 adds `80_jobs.sql`.
- Every table: id, created_at, `is_test boolean not null default true`, and the version stamps blueprint ARC-10 names where they apply.
- Append-only: events, versions, version cells, approvals and entry lines refuse UPDATE and DELETE (trigger). Facts and entries change by writing a new version row.
- Constraints: an entry's lines net to zero (checked when the entry is closed); a fact has exactly one source pointer kind; origin is one of the five in EV-10; fact status is one of the three in EV-8; an account has one GIFI code per version.
- Row-level security enabled on every table, no policies (deny-all).
- `src/contracts/records.ts` mirrors the tables; `ids.ts` names the id kinds. `index.ts` re-exports these two only; later contracts are imported by their own path.

## Acceptance checks
1. EV-1, SEC-7: an UPDATE or DELETE of an event, version, version cell or approval fails.
2. TB-2: an entry whose lines do not net to zero cannot be closed.
3. EV-5: a fact with no source pointer, or with two, is refused.
4. EV-10: an origin outside the five is refused.
5. EV-8: a fact status outside the three is refused.
6. TB-3: an account with two GIFI codes in one version is refused.
7. SEC-6: row-level security is on for every table in schema returns (a catalog query).
8. Every table has `is_test`.
9. A test inserts one row into every table from a typed object, so the types and the tables agree.
