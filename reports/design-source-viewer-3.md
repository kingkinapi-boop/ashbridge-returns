## 4. Parts used that `design/basis/parts.md` lacks

GOV.UK: textarea, checkboxes (small), label, hint, form group, list, link, visually hidden, heading and body styles, width container, main wrapper. MOJ: sub navigation, search. The identity bar is "to be reviewed" in the basis; the MOJ alert is official. Everything else used is in the basis (button, details, error message, error summary, fieldset, generic header, input, inset text, radios, skip link, summary list, table, tag, warning text).

Composed outside GOV.UK and MOJ, each with its reason, are listed class by class in `notes.md` (the pane and splitter, the page image box and its zoom controls, the OCR highlight layer, the sheet and ledger views of a source, the step list, the second-window controls).

## 5. Notes for the Lead

- The pane depends on the D13 shell (identity bar and record tabs); D13 must keep the work column as the scroll area.
- Zoom has buttons only. There is no previous-number key (D01's list has none).
- The header search on the plain pages is a stand-in outside the return shell.
- Inline styles beyond rule 1 (the page width, and the pane width variable `--app-pane-w` on the split): rule 1 names only the box position. Amber flag for the rules list.
- The verify script exempts url() in the official compiled stylesheet from the "no external reference" lint.
- The sign-out test is an extra here; V00 owns it.
- The removed-clause lint derives from the blueprint's own removal markers, so none is named here.
- Step buttons needed a 25 px height and a 24 px width to pass axe target size at 320 px.
- A failed page image shows an error summary, so the page title must start "Error: ": a shared test is advised for every pane that can fail to load.
- Tall states use a 30% page-area bar for an error or an undo form (60% elsewhere): the form is in view in full, which is what matters. The Undo form opens in a full-width row under the decided row, with a one-line reason box.
- The void state opens scrolled to the changed cells; its list has 2 rows.
- The recorded message is one visible line ("Recorded. 6 left. Next: ...") plus a longer sentence announced to screen readers.
- The candidate radio label no longer carries the group word visibly; it is in the meta line and in visually hidden text.
- A change of the second window choice is announced last, after a short delay, so it is not overwritten by the source announcement.

## 6. Choices for Zo (two)

1. One decision place or a button on each row. Drawn: the decision lives in one slot at the foot of the pane, and rows have no primary button (Undo only on a decided row). The other way puts a primary button on every row, faster for a long list but several places to act and a risk of a mistaken click. Recommendation: one decision place.
2. When the second window follows, what the pane does. Drawn: the pane hides, the list takes the full width and the decision moves above the list, so there is one copy of the source. The other way keeps the pane as a mirror of the second window. Recommendation: hide it.
