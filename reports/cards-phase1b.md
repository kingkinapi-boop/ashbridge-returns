## Ambers

- A08: the project's orders are `ai-project/ORDERS.md` (not `CLAUDE.md`) and its settings `ai-project/settings.json`, run with the exchange folder as the working folder outside the repo. Why: no Claude Code session in this repo loads the project's orders, and the project never loads the repo's. Reverse: a separate repo for the project.
- A08: the model gets the Read tool only, limited to its job folder; code, not the model, writes the outbox file. Why: AI-8 says AI steps have no tools that write, and ARC-22 says the project has no other write access. Reverse: let the project write `outbox/` itself through a scoped Write permission.
